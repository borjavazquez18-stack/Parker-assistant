PARKER V0.2 — paquete PWA listo para publicar

PUBLICACIÓN RÁPIDA:
1. Sube TODO el contenido de esta carpeta a un hosting estático HTTPS.
2. La carpeta raíz debe contener index.html, manifest.webmanifest y sw.js.
3. Abre la dirección HTTPS en Chrome Android.
4. Pulsa “Instalar PARKER” si aparece, o Chrome > ⋮ > “Añadir a pantalla de inicio” / “Instalar aplicación”.

IMPORTANTE:
- Para que la instalación PWA y el service worker funcionen de forma fiable, usa HTTPS.
- El prototipo no contiene todavía IA externa real ni activación por palabra “Parker” en segundo plano.
